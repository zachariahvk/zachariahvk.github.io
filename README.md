# Portfolio — Zachariah V. Kurien

Content marketing portfolio. Single-page static site, no build step, no dependencies.

**Live:** __SITE_URL__

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site — markup and CSS in one file |
| `preview.png` | 1200×630 card shown when the link is shared (LinkedIn, WhatsApp, Slack) |
| `favicon.svg` | Browser tab icon |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

## Editing

Edit `index.html`, commit, push. GitHub Pages redeploys in about a minute.

To add a piece of work, copy an existing `.entry` block inside the relevant `.group`
and change the title, description and link.
